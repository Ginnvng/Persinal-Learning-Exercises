# Personal-learning-exercises

This repository is for learning programming.

It may contain messy or suboptimal code.
Suggestions and improvements are very welcome.

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `学校课程/` | 学校课程的实验和作业，按“学期-课程”命名，如 `大一上-C语言/`、`大二上-Java/` |
| `算法训练/集训/` | 寒暑假算法集训的训练题和训练赛 |
| `算法训练/刷题/` | 各 OJ 平台的刷题和比赛（nowcoder、PTA 等） |
| `自学/` | 自学课程，如 CS50 |
| `小项目/` | 自己做的小程序 |

- `大二上-Java/` 是一个 IntelliJ 项目，每次作业是 `src/` 下的一个包，按日期命名，如 `hw26_09_08`。
- Python 虚拟环境不提交，需要时重建：`python3 -m venv myenv && myenv/bin/pip install -r requirements.txt`。
