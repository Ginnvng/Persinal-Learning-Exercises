# 单思雨的19岁生日祝福 🎉

一个极简优雅的生日祝福应用，采用**苹果设计语言**重构，为单思雨的19岁生日献上最诚挚的祝贺。

---

## ✨ 设计特色

### 苹果风格美学

- **极简配色** - 精选蓝紫色、青蓝色、玫瑰色、琥珀色系列，色彩柔和优雅
- **精细排版** - 更小的卡片尺寸，更大的圆角，更细的边框
- **流畅动画** - 更高的帧率（8ms）、更柔和的缓动曲线（正弦混合）
- **智能布局** - 卡片分布更均衡，视觉重心自然上移

### 品质优化

- 弹窗数量：120个（↓ 从300个）- 减少混乱，提升品质感
- 弹窗间隔：180ms（↑ 从120ms）- 更从容的节奏
- 动画参数：全面优化，更流畅更细腻
- 文字大小：14px普通卡片 → 22px终章（更清晰的层级）

## 🚀 快速开始

### 运行程序

```bash
python main_单思雨.pyw
```

### 修改参数

编辑文件顶部的配置区：

```python
# 1) 人名（必改）
NAME = "单思雨"

# 2) 弹窗参数
MAX_WINDOWS = 120              # 弹窗数量
POP_INTERVAL_MS = 180          # 弹窗间隔（毫秒）
SPAWN_DURATION_SEC = 12        # 播放总时长（秒）

# 3) 卡片尺寸
NORMAL_WIDTH_RANGE = (280, 380)   # 普通卡片宽度范围
NORMAL_HEIGHT_RANGE = (110, 150)  # 普通卡片高度范围

# 4) 主题选择
THEME_MODE = "apple_light"     # 现在仅支持这个主题
```

## 📝 自定义祝福语

编辑 `BINDABLE_BLESSINGS` 和 `GENERIC_BLESSINGS` 字典：

### 可绑定祝福（带名字）

```python
"新年祝福": [
    "{name}，19岁的你，愿用青春浇灌梦想",
    # 在 {name} 处插入收礼者的名字
]
```

### 通用祝福（不带名字）

```python
"生活/趣味": [
    "热爱可抵岁月漫长，心怀热爱，永远年轻",
]
```

## 🎬 动画流程

1. **前12秒** - 弹窗持续弹出，展示各类祝福
2. **第10秒后** - 停止创建新弹窗，准备进入终章
3. **第12秒** - 所有普通弹窗开始淡出
4. **第14秒** - 终章卡片（大卡片）出现，显示最后的祝福
5. **用户点击"好"** - 终章卡片淡出，程序结束

## 🎯 设计理念

这个重构秉承了Apple的设计哲学：

- **Less is more** - 减少装饰，突出内容
- **Typography first** - 文字是主角，排版是设计
- **Smooth motion** - 动画应该是自然的、不突兀的
- **Color harmony** - 颜色搭配要和谐，不要过饱和
- **White space** - 留白很重要，不要挤满屏幕
