## 单张卡片对比


## 动画流程对比

### Before - 老式节奏

```
创建弹窗    播放中期    淡出收尾     终章      确认
├──────────┼────────────┼──────────┼───────┤
0s        3s           8s          12s     结束
  
每0.12秒创建1个 → 混乱、杂乱、难以聚焦
```

### After - 苹果风格节奏

```
创建弹窗    创建继续    停止创建    淡出开始  终章出现  确认收尾
├──────────┼──────────┼──────────┼────────┼────────┼──────┤
0s        3s         10s        10.5s    12s      结束

每0.18秒创建1个 → 均衡、优雅、让人能跟上
```

#### 关键参数对比

```
帧刷新率：          10ms  →  8ms  (+20% 流畅)
淡入时间：         280ms  → 350ms (更从容)
淡出范围：   900-1600ms  → 800-1400ms (更精准)
弹窗总数：         300个  → 120个 (-60%)
出现延迟：        2200ms  → 1800ms (更快响应)
```
